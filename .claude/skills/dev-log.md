# 开发日志 Skill

**触发词**: `开发日志`、`写日志`、`今日成果`、`工作记录`、`dev-log`、`devlog`

当用户消息包含以上任意关键词时，调用此 Skill。

## 流程

### 1. 读取今日成果

```bash
git log --oneline -5               # 查看最近提交
git show --stat HEAD               # 最新提交的文件变更统计
git log --since="today" --oneline  # 今天所有提交（失败则跳过）
```

如果今天没有新提交，改为 `git diff --stat HEAD`。

### 2. 读取 Plan 进度

- `Glob *.md` 扫描项目根目录计划文件
- `Glob .claude/**/*.md` 扫描 `.claude/` 下的计划/文档
- 根据对话上下文判断哪些计划与今天工作相关
- 标注状态：✅ 完成 / 🔶 部分完成 / ❌ 未开始

### 3. 命名与路径

文件名格式：`log/M.DD开发日志.md`，写入**项目根目录**的 `log/` 文件夹。

```
📁 TexApi/                  ← 项目根目录
├── 📁 log/                 ← 日志放这里（不是 .claude/log/）
│   ├── 8.06开发日志.md
│   └── 8.07开发日志.md
├── 📁 .claude/
│   └── skills/dev-log.md   ← 本 skill 文件
├── 📁 src/
└── ...
```

- M = 月份，无前导零（`8`、`12`）
- DD = 日期，有前导零（`06`、`15`）
- 例：`log/8.06开发日志.md`、`log/12.01开发日志.md`
- 目录不存在时先 `mkdir -p log`

### 4. 写入文件

写入 `log/M.DD开发日志.md`（项目根目录下）。

## 日志模板

```markdown
# 开发日志

## YYYY-MM-DD

### 今日成果

**Commit**: `<commit-hash>` — <commit-message>

**改动量**: N 个文件，+X 行，-Y 行

#### 1. <任务一标题>

- <具体改动点>
- ...

#### 2. <任务二标题>

- ...

### 当前 Plan 进度

> 相关计划文件：<列出本次参考的 plan 文件路径>

| 计划项 | 状态 | 说明 |
|--------|------|------|
| xxx   | ✅   | xxx  |

**整体进度**：<根据实际情况估算>

### 明日计划

- <从相关 plan 中提取下一个待做任务，或根据对话上下文合理建议>
```

## 注意

- 路径是 `log/`（项目根），**不是** `.claude/log/`
- 每次动态扫描项目下的 plan 文件，不要写死文件名
- 进度百分比根据实际完成情况计算
- 明日计划优先延续当天未完成的工作
