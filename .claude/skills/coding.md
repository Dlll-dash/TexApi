# 编码 Skill

当用户确认方案后开始实施代码时，遵循以下规则。

## 流程

### 1. 确认方案

用户通过 `ExitPlanMode` 批准方案后，进入实施阶段。

### 2. 实施代码

按方案执行改动：新建/修改文件、编译、测试。

### 3. 同步方案描述

**实施过程中或完成后，必须将实际实现与计划的偏差同步到方案文件中**。包括但不限于：

- 技术方案变更（如 A 方案改为 B 方案）
- 类/方法/注解命名变更
- 新增或删除的文件
- 架构调整（如去掉中间层、合并方法等）
- 流程变更（如鉴权链路的改动）

**原则**：代码是真相，方案描述必须反映代码的实际状态。不能让方案文件变成过时文档。
